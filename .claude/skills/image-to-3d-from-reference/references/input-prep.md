# Input prep (shared Meshy / Tripo / agent)

Copied from product guidance + game-art practice. Bad inputs dominate failure.

## Do

- One subject, centered, filling most of the frame  
- Plain / white / transparent background  
- Front or ¾ for the primary shot; add true side/back if possible  
- Even, soft lighting  
- Sharp focus; ≥1024px short side when possible  
- For characters: full body visible; avoid extreme foreshortening  

## Don’t

- Busy scenes / multiple subjects  
- Tiny subject with huge empty margins  
- Hard directional shadows you don’t want in texture  
- Mirrors, chrome, glass, dense fur as sole cue (both products struggle)  
- Cropped limbs you still need reconstructed accurately  

## Illustration / concept art refs (Warcrest)

Stylized paintings are valid. Expect:
- No real photometric depth → agent must **author** side/back into the card  
- Flat cel shading → prefer region materials over photo PBR  
- T-pose concept sheets are gold (Meshy Pose toggle exists for the same reason)

## Prompt adjunct (Meshy/Tripo texture stage)

Shape from image; materials from short text:  
`"matte green leaf enamel, brushed gold trim, lavender skin, emissive green eyes"`.
