Warcrest · HUD · Command Foundry

Every button, cast
from one mould.

A full inventory of the game's commands — orders, stances, selection, build, train, management, the hero kit, and gear — each struck as one cohesive Warcraft-III-style command button: a gold-over-stone bevel around a hand-cut bronze-relief icon, with a category gem, hotkey, and cost. One frame, one icon language, so any of them can drop straight into the command hub and read as a set.

◆ 61 command buttons · 1 shared frame · 1 relief palette
E 90
  • Gold-over-stone bevel. The uniform WC3 frame — top-lit gold rim, dark stone well, inner gloss. Every button shares it.
  • Bronze-relief icon. One gradient (#relief) casts every glyph as the same struck metal, so 58 icons read as one set.
  • Category gem (top-right). Colour-codes the button's family at a glance without breaking the shared frame.
  • Hotkey (top-left) & cost (bottom-right, coin) — the WC3 command-card conventions, kept.
